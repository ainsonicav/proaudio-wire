Apogee plugins (Plugin Alliance versions) 업데이트 소식

Apogee가 2026년 10월 1일부터 자사 플러그인의 구매·다운로드·라이선스·업데이트를 Plugin Alliance로 이전합니다. 새 버전은 iLok 없이 사용할 수 있고 모든 플러그인 창 크기 조절(scalable windows)을 지원하며, MOD EQ 6과 MOD Comp는 Plugin Alliance 제품으로 업그레이드하는 옵션이 제공됩니다. 기존 사용자는 몇 주에 걸쳐 이메일로 무료 바우처를 받으며, 기존 iLok 버전도 계속 쓸 수 있습니다.

원문: “Apogee plugins are moving to Plugin Alliance, which will become the new home for purchasing, downloading, licensing, and updating Apogee software.”
