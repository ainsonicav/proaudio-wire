Sound Devices Wave Agent X 신제품 소식

Sound Devices가 macOS·Windows용 WAV 파일·메타데이터 관리 유틸리티 Wave Agent X를 공개했습니다. 4GB 초과 파일과 최대 32트랙, 32비트 플로트를 지원하고, 오토메이션 가능한 32채널 믹서와 메타데이터 일괄 편집 기능을 갖췄습니다. 현장 녹음 믹서와 포스트 편집자를 위한 도구로 사운드 리포트(PDF/CSV) 내보내기도 지원합니다. macOS 12·Windows 10 이상에서 무료로 사용할 수 있습니다.

원문: “Wave Agent X WAV File Utility for Mac OS and Windows Computers Next Generation Audio File and Metadata Management”
