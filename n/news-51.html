Calrec Type RT, Apex M6 신제품 소식

Calrec이 IBC 2026에서 Type RT 콘솔과 Apex M6 모듈러 I/O 플랫폼을 공개했습니다. Type RT는 6·12·18 모터 페이더 구성의 팬리스 탁상형 일체형 콘솔로 ST2110을 기본 지원하고 Dante·MADI는 옵션입니다. Apex M6는 1U에 모듈 슬롯 6개와 512×512 내부 라우터를 갖추고 ST2110-30, AES67, Dante, MADI 등을 지원합니다. 경기장, 라디오, 교회, 원격 제작, IP 전환 방송사를 겨냥했습니다.

원문: “Calrec expands its IP ecosystem with new, ready-to-use Type RT console and Apex M6 Modular I/O Platform at IBC 2026.”
